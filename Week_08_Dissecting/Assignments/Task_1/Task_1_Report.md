# Task 1 Report

I use GitHub Copilot through the Copilot SDK in VS Code. In this environment, the assistant's system prompt is managed by the host and is not exposed as an editable workspace setting, so I cannot make or screenshot a highlighted change to it.

As alternatives, GitHub Copilot supports repository custom instructions in `.github/copilot-instructions.md` and reusable prompt files in `.github/prompts/`. These can guide Copilot's responses without changing its system prompt.
